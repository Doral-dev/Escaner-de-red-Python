
Pasos para ejecutar y usar esta herramienta:


1. Clona o descarga el repositorio en tu máquina y sitúate en la carpeta del proyecto ejecutando estos comandos:

```
git clone https://github.com/Doral-Ciberseguridad/Escaner-Red-Auditoria-Python.git
```

```
cd Escaner-Red-Auditoria-Python
```


2. Instala las dependencias necesarias ejecutando en tu terminal:

```
pip install python-nmap
```



3. Lanza el script ejecutando en tu terminal:

```
python "Escaner de red.py"
```



4. Selecciona el tipo de opción que deseas realizar en el menú interactivo introduciendo un número del 1 al 6



5. Introduce los parámetros solicitados según la opción elegida (como las IPs o puertos objetivo) y visualiza los resultados automáticos del análisis de red en pantalla
